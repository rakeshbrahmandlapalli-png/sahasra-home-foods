 About 5 minutes. Free. No card.

 I cannot do this part for you — it needs you signed in, and I am not

───────────────────────────────────────────────────────────────────────
 FIRST: MAKE THE UPLOAD FOLDER
───────────────────────────────────────────────────────────────────────
 ALREADY DONE — the folder  Desktop\SAHASRA-LIVE  is waiting for you.

 It holds only the three files that belong online:
     index.html    admin.html    menu-source.js

 Your working notes (setup/, README.txt, this file) were deliberately
 left out. Nothing in them is secret, but they have no business being on
 a customer-facing website.


───────────────────────────────────────────────────────────────────────
 THEN: DROP IT ON VERCEL
───────────────────────────────────────────────────────────────────────
 1. Go to  https://vercel.com/drop
 2. Drag the SAHASRA-LIVE folder onto the page.
 3. It asks which team to deploy to, and for a project name.
        name it:  sahasra-home-foods
        team:     your own — see the box below
 4. Press Deploy. About twenty seconds.

 You get an address like  https://sahasra-home-foods.vercel.app
 It is live worldwide the moment it appears.

 There is no build step — three plain HTML files with no package.json,
 so Vercel serves them exactly as they are.

 The edit screen will be at  /admin.html
 e.g.  https://sahasra-home-foods.vercel.app/admin.html

────────────────────────────────────────────────────────────────────
 IF YOU PREFER NETLIFY INSTEAD
───────────────────────────────────────────────────────────────────────
 Identical idea:  https://app.netlify.com/drop  — drag the folder on.
 Note that Netlify deletes the site after an hour unless you sign up
 to claim it. Vercel makes you pick the account up front instead.
 Either is fine. Use whichever you will actually remember the login to.


───────────────────────────────────────────────────────────────────────
 WHEN YOU CHANGE SOMETHING LATER
───────────────────────────────────────────────────────────────────────
 Prices, names, photos → use the edit screen at /admin.html . Nothing
 to re-upload. That is the whole point of the database.

 Only if I change the CODE do you re-upload: go back to
 https://vercel.com/drop , drag the folder again, and give it the SAME
 project name — it replaces the existing site rather than making a
 second one.


───────────────────────────────────────────────────────────────────────
 A PROPER DOMAIN (OPTIONAL, COSTS MONEY)
───────────────────────────────────────────────────────────────────────
 Something like sahasrahomefoods.com is roughly Rs 900–1,200 a year from
 Namecheap, GoDaddy or Cloudflare. Vercel connects it for free:
 Project → Settings → Domains → Add, then follow its instructions.

 The family should buy and own this, not you. A business that does not
 own its own domain cannot leave whoever does.
